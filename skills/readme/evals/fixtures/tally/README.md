# Tally 🚀

Welcome to **Tally** — a powerful, blazing-fast, and elegant solution for all your text-counting needs! In today's fast-paced world, understanding the size of your files is more important than ever. Tally empowers developers to seamlessly gain insights into their codebases.

## ✨ Features

- 📊 **Comprehensive Counting**: Tally leverages cutting-edge algorithms to count lines, words, and characters.
- ⚡ **Lightning Fast**: Built for performance at scale.
- 🔧 **Flexible Output**: Supports both table and JSON formats, giving you the flexibility you need.
- 🎯 **Smart Sorting**: Sort by lines, words, or chars to focus on what matters most.

## 🛠️ Usage

It's worth noting that Tally is incredibly easy to use. Simply run `python3 tally.py` followed by the files you want to count. You can also pass `--json` to get JSON output, which is perfect for integrating with other tools and pipelines. Additionally, the `--sort` option accepts `lines`, `words`, or `chars` and sorts rows largest first. Line counts are newline counts, so a file without a trailing newline reports one fewer line than an editor shows.
