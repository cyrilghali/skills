# Immune memory: reviewer notes for the public-health series

Plain summary of standard textbook immunology, checked by the series' medical reviewer.

## First encounter (primary response)

- The first time the immune system meets an antigen, few B cells and T cells match it. The matching cells must multiply before the response is strong.
- Antibody levels from a first response take about one to two weeks to peak.

## Memory

- After the first response, most of the matching cells die off, but some stay on as long-lived memory B cells and memory T cells.
- Memory cells can last for years, and for some antigens for decades.
- During the first response, B cells in the lymph nodes mutate their antibody genes; the cells whose antibodies bind the antigen more tightly are selected to survive. This is called affinity maturation.

## Second encounter (secondary response)

- On a later encounter with the same antigen, memory cells respond within a few days, faster than the first time.
- The secondary response produces more antibodies, and antibodies that bind more tightly, than the primary response.
- Often the second response clears the germ before the person feels ill.

## Vaccines and boosters

- A vaccine triggers a primary response without the disease, so the memory is in place before a real infection.
- Some vaccines need more than one dose, called boosters, to build a strong and lasting memory.
