# doc-pedagogique rubric

Noter le document généré sur 20. PASS ≥ 15 avec zéro dimension à 0.
**Règle anti-hallucination : toute pénalité cite le passage exact fautif (verbatim). Une pénalité sans citation est nulle.**

| Dimension | Points | 0 si… |
|---|---|---|
| Fil rouge concret nommé, introduit tôt puis **rejoué** dans chaque option (sauf mémo court : un exemple d'une phrase suffit) | 0-4 | aucun exemple incarné |
| Décor avant jargon : chaque terme technique expliqué à sa 1re apparition ; le problème compréhensible en 60s par le lecteur cible du case | 0-4 | ≥2 termes utilisés avant introduction |
| Verdicts honnêtes : « où ça coince » par option, la limite ou le défaut majeur fourni dans la matière est visible et pesé ; sans option dans la demande, rien n'est inventé pour en fabriquer | 0-4 | défaut fourni masqué ou minimisé |
| Français rédigé : prose complète, zéro télégraphe/fragment recopié de la matière, typographie française (« », espaces insécables, majuscules accentuées) | 0-4 | ≥2 blocs télégraphiques recopiés |
| Proportion : structure adaptée à la demande (structure complète pour un comparatif riche, resserrée pour une demande courte ; sans option à comparer, aucune section options, comparaison ou recommandation) ; décisions finales en questions quand il y a un choix | 0-4 | template complet déroulé sur une demande courte, options ou recommandation fabriquées là où la demande n'en contient pas, ou comparatif riche livré sans structure |

Le juge lit d'abord le case (matière + piège), puis le document, puis remplit la grille dimension
par dimension avec citations. Verdict final : PASS/FAIL + les 2 améliorations les plus rentables.
